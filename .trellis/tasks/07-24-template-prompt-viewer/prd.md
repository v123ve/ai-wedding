# 模板卡片查看与复制完整提示词

## Goal

在模板列表页面，让用户能在模板卡片上展开查看完整提示词（basePrompt、negativePrompt、prompt_list），并一键复制用于其他网页端生图。

## Requirements

### R1: 展开/收起提示词
- 每个模板卡片增加一个"查看提示词"按钮
- 点击后卡片向下展开，显示完整提示词内容
- 展开状态可收起

### R2: 展示内容
- **基础提示词 (Base Prompt)** — 完整中文文本，带复制按钮
- **负面提示词 (Negative Prompt)** — 完整英文文本，带复制按钮
- **组图提示词列表** — 每张图的 prompt 逐条展示，带独立复制按钮
- **一键复制全部** — 顶部一个"复制全部"按钮，合并所有内容

### R3: 复制交互
- 复制成功后按钮显示"已复制"状态（1.5s 后恢复）
- 使用 `navigator.clipboard.writeText()`
- 优雅的视觉反馈

### R4: 页面样式
- 展开区域使用深色半透明背景（与卡片风格一致）
- 提示词文本使用等宽字体，行距舒适，适合阅读
- 每段提示词有明确的分隔和标签
- 复制按钮样式精致，悬停可见

## Constraints

- 仅修改 `app/templates/[domain]/page.tsx`（服务端组件查询扩展 + 渲染）
- 公共 API `/api/templates` 不修改（保持提示词隐藏）
- 仅在 domain 页展示，首页模板列表不加
- 遵循现有设计语言（金色强调色、深色主题）

## Acceptance Criteria

- [ ] 每个模板卡片有"查看提示词"按钮
- [ ] 展开后完整显示 basePrompt、negativePrompt、所有 prompt_list
- [ ] 每段有独立的复制按钮，复制后显示"已复制"
- [ ] "复制全部"按钮合并所有内容
- [ ] lint + typecheck 通过
